II. Connected System Infrastructure

Oracle ERP 88% LOAD

Core relational backbone; high validation strictness creating downstream hold queues.

WebCenter 65% LOAD

Asset approval pipeline and customer proof routing; frequent re-entry iterations.

Zendesk 92% LOAD

Triage intake funnel; high-velocity exception handling and customer inquiries.

Wrike 45% LOAD

Task staging and project scheduling; manual handoffs between department leads.

MS Teams / Chat 78% LOAD

Informal backchannels; critical operational resolutions lost to unsearchable chats.

Direct Email 84% LOAD

Siloed message chains; single-point-of-failure communication dependencies.

III. Friction & Pattern Metrics

Re-entry Tax

The computational and cognitive cost of bouncing orders back to intake for minor schema omissions.

Dark Communication

High-value exceptions solved via instant message rather than documented system updates.

Load-Bearing Person

Single human nodes holding custom procedural knowledge necessary to bridge disconnected tools.

Workaround Loop

Informal side-channels established by teams to bypass high-friction system checkpoints.
